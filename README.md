# LBG Pricing Calculator

A simple, powerful web app for calculating LBG pricing across geographies and delivery models.

## Features

- 🌍 Multi-geography support (UK, India, Philippines, South Africa)
- 📊 Real-time pricing calculations
- 📈 Multi-year projections
- 💰 Margin analysis
- 📋 Deal summaries

## Quick Start

### Cloud (Easiest)
Visit: [LBG Pricing Calculator](https://lbg-pricing-calculator.streamlit.app)

### Local
```bash
pip install -r requirements.txt
streamlit run lbg_pricing_app.py
```

## Parameters

- **Geography**: Select region (affects base costs)
- **FTEs**: Number of full-time equivalents (10-500)
- **Complexity**: Low, Medium, High, Very High
- **Capability**: Account Servicing, Fraud Response, Compliance, Data Analytics
- **Years**: Contract duration (1-5 years)

## Outputs

- **ACV**: Annual Contract Value
- **TCV**: Total Contract Value
- **Margin $**: Margin in dollars
- **Margin %**: Margin percentage
- **Multi-Year Projection**: Year-by-year breakdown
